# Team Meckartans website (Next.js)

The Next.js (App Router) version of the site built from **"Meckartans Website.pdf"** (the team's requirements brief).
It is a one-to-one port of the Vite/React build in `../meckartans-web`: same content, media, design tokens, styles,
components and animations. Only the framework layer differs (routing, server rendering, fonts).

| Route | Page | Brief |
|---|---|---|
| `/` | Home: logo, team photo/video slideshow, tagline, intro, shortcuts to every page, major achievements | p.4, p.9 |
| `/about` | About text (verbatim), what we do, workshops & events, social links | p.5, p.11 |
| `/team` | Faculty advisors + executive committee cards (photo, name, position, LinkedIn) | p.6 |
| `/gallery` | Full-screen video, then ALL / VEHICLES / … / EVENTS filters (`?c=`) over a 3D photo field (three.js; scroll to fly, drag to pan, click to open) or the mixed-size grid (`?view=grid`; default for reduced motion / no WebGL), lightbox | p.7 |
| `/garage` | All 18 vehicles by IC / Electric / ATV; detail sheet (`?v=mk11`) with specs, events, leadership, photos | p.8 |
| `/achievements` | Timeline, newest first (`#fkdc-4` anchors) | p.9 |
| `/support` | Support our journey (CFR video, crowdfunding, bank) + sponsorship portal (`#sponsorship`) | p.10 |
| footer (`#contact`) | Captain / Manager / Faculty Advisor, map, social icons, on every page | p.12 |

**Before launch:** see [CONTENT-NEEDED.md](CONTENT-NEEDED.md). Missing items show a dashed "To be added" marker.

## Run

```bash
npm install
npm run dev      # http://localhost:5190
npm run build    # every page is prerendered as static HTML
npm start        # production server, http://localhost:5191
```

Requires Node 20+. Deploys as-is to Vercel or any Node host. For plain static hosting, add `output: "export"` to
`next.config.ts` (nothing in the app needs a server: the `?c=` / `?v=` parameters are read in the browser).

## Structure

```
src/app/            routes: layout.tsx (fonts, metadata, nav/footer, smooth scroll), one page.tsx per route, not-found
src/views/          the page components (client components, server-rendered)
src/components/     nav, footer, page hero, lightbox, ui pieces, "To be added" marker
src/content/        ALL text, names, results, links: edit these, not the components
src/lib/            GSAP setup + reveal hook, utils
src/styles/tokens.css   generated from tokens.json (colours, fonts, radii, motion)
public/media/       pre-optimised images (WebP) and video
scripts/            media pipeline (inventory, build_media, build_montage) + the one-off port script
```

## Editing content

All text, names, results and links live in `src/content/`: `site.ts`, `team.ts`, `vehicles.ts`, `achievements.ts`,
`support.ts`, plus `gallery.json` (generated by `scripts/build_media.py`).

Design tokens: edit `tokens.json`, then
`node ../skills/design-system/scripts/generate-tokens.cjs --config tokens.json -o src/styles/tokens.css`.
Fonts are self-hosted by `next/font` in `src/app/layout.tsx`; the tokens point at its CSS variables
(`--font-archivo`, `--font-roboto-mono`).

## What changed from the Vite build (and why)

| Area | Vite build | Next build |
|---|---|---|
| Routing | React Router (`Link to`, `NavLink`, `useSearchParams`) | App Router (`next/link`, `usePathname`; `?c=`/`?v=` read with `useSearchParams` inside a Suspense boundary and updated with `history.replaceState`) |
| Rendering | client-only | every page prerendered to static HTML, then hydrated |
| Load animations | started from an empty page | the server HTML would flash before GSAP starts, so a pre-paint script adds `js` and CSS hides `.fouc` / `.reveal` until their animation runs (falls back to visible after 4s or with reduced motion) |
| Video size choice | read `window` during render | chosen after mount (poster shows first), since the server has no viewport |
| Vehicle detail sheet | portal rendered immediately | rendered after mount (portals need `document`) |
| Footer year / "years racing" | computed in the browser | build year in the HTML, updated to the visitor's year after mount |
| Fonts | Google Fonts `<link>` | `next/font` (same families and width axis, self-hosted) |
| Page titles | one title for every page | per-page titles ("Gallery &#124; Team Meckartans") |
| Images | plain `<img>` | unchanged plain `<img>`: the media is already optimised WebP; `next/image` would change markup and layout |

## Media pipeline

```bash
python scripts/inventory.py <sheet-dir>     # index + dedupe Meckartans_Gallery, numbered contact sheets
python scripts/build_media.py               # gallery/vehicle/hero/team images (WebP) + src/content/gallery.json
python scripts/build_montage.py <ffmpeg>    # gallery background reel
```

`build_media.py` assigns gallery categories by inventory id; re-check its `CATS` lists if `inventory.py` is re-run on
a changed library. Team portraits and the logo come from the brief PDF's images (`PDF_IMG_DIR=<folder>`).
